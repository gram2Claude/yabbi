# Анкета проекта — Yabbi (источник БЕЗ API)

> ⚠️ Отличие от стандартной анкеты: у Yabbi **нет публичного API**. Статистика забирается из
> личного кабинета рекламодателя по **cookie-сессии**; «методы» передаются в параметрах URL.
> Поэтому вместо «URL документации API» здесь — точка входа кабинета и сводка `info/00_yabbi_source.md`.

## B. Параметры источника (определены разведкой, см. info/00_yabbi_source.md)

```
B1. Тип авторизации:            cookie-сессия (форма входа POST /login?method=account,
                                поля login/password; ОБЯЗАТЕЛЬНЫ заголовки Referer + Origin).
                                Сессия ~1 час, продлевается запросами; клиент перелогинивается сам.
B2. Базовый URL:                https://my.yabbi.me
B3. Паттерн запроса:            синхронный GET; «метод» — в query (?method=…) или в пути.
                                Ответ — JSON (Content-Type: text/plain). Пустой период → null.
B4. Формат дат в запросе:       Unix-время в МИЛЛИСЕКУНДАХ (startTime/endTime). endTime ВКЛЮЧАЕТ свой день.
B5. Пагинации нет:              справочник/статистика отдаются целиком за период.
B6. Сжатие:                     обязательно Accept-Encoding: gzip (обходит сетевой затык >16 КБ; requests — по умолчанию).
B7. Забор по дням:              статистика по кампаниям/баннерам — по 1 дню за запрос.
B8. Охват (reach):              кумулятивная метрика — накопительно за [global_start_date, D], НЕ суммируется по дням.
B9. Rate limit:                 явных лимитов не наблюдалось; повтор с backoff при сетевой ошибке/протухшей сессии.
```
